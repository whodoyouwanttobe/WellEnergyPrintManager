# 🖨️ PDF Print Manager

**Автоматизированная система печати чертежей и технической документации.**

Приложение анализирует PDF-файлы (чертежи, проектная документация), определяет формат каждой страницы (А0–А4, кратные форматы по ГОСТ) и автоматически маршрутизирует печать:

- **A4 / A3** → лазерный принтер (HP LaserJet Pro MFP M435 PCL 6)
- **A2 / A1 / A0 / кратные** → плоттер (Canon TM-350)

---

## 📋 Возможности

| Функция | Описание |
|---|---|
| 📊 Анализ форматов | Определение A0–A4, кратных форматов (A3x3, A4x7) |
| 🔀 Маршрутизация | Автоматическое распределение по принтерам |
| 🖨️ Тихая печать | Через SumatraPDF CLI без открытия окон |
| 🔬 Пробная печать | Проверка одной страницы перед полной печатью |
| 📋 История | SQLite БД: что, когда и куда было напечатано |
| ✅ Отслеживание | Маркировка напечатанных файлов (✅/⚠️/⬜) |
| 📡 Мониторинг | Статус принтеров через Windows API (win32print) |
| ⚠️ Оповещения | Крупное окно при замятии / нет бумаги / ошибке |
| ⚙️ Настройки | Гибкая настройка имён принтеров и параметров |

## 🔧 Установка и настройка

### 1. Зависимости Python

```bash
pip install PyMuPDF pywin32
```

> **Примечание:** `pywin32` нужен для мониторинга статуса принтеров.
> Если его не установить, приложение будет работать, но без мониторинга.

### 2. SumatraPDF (для печати)

SumatraPDF — портативный PDF-ридер с поддержкой CLI-печати.
**Права администратора НЕ НУЖНЫ.**

1. Скачайте **SumatraPDF Portable** (`.zip`):
   https://www.sumatrapdfreader.org/download-free-pdf-viewer

2. Разархивируйте `SumatraPDF.exe` в папку `tools/`:
   ```
   WellEnergyProject/
   └── tools/
       └── SumatraPDF.exe
   ```

3. Или укажите путь во вкладке **«Настройки»** приложения.

### 3. Проверка имён принтеров

Откройте вкладку **«Настройки»** → раздел **«Принтеры в системе»**.
Проверьте, что имена принтеров соответствуют тому, что установлено в Windows:

- **Лазерный:** `HP LaserJet Pro MFP M435 PCL 6`
- **Плоттер:** `Canon TM-350`

Если имена отличаются — измените в настройках и нажмите **«Сохранить»**.

## 📖 Как пользоваться

### Шаг 1: Выбор папки
Нажмите **«Обзор»** и выберите папку с PDF-файлами.
Приложение автоматически:
- Просканирует все PDF
- Определит формат каждой страницы
- Проверит историю — что уже было напечатано
- Пометит файлы: ✅ (напечатан), ⚠️ (частично), ⬜ (не печатался)

### Шаг 2: Анализ (вкладка «Анализ»)
Кликните на файл в списке — справа появится:
- Группировка страниц по формату
- Маркировка принтера: `[HP]` или `[Canon]`
- Подробная таблица: формат, размеры, ориентация
- Информация о статусе печати

### Шаг 3: Печать (вкладка «Печать»)
- Посмотрите **план печати**: что пойдёт на HP, что на Canon
- Нажмите **«Пробная печать»** — напечатает одну страницу для проверки
- Нажмите **«Начать печать»** → подтвердите в диалоговом окне
- Следите за прогрессом и статусом принтеров

### Шаг 4: История (вкладка «История»)
- Полный журнал всех задач печати
- Дата, файл, принтер, страницы, статус
- Кнопка очистки для сброса истории

## ⚙️ Параметры печати

### HP LaserJet Pro MFP M435 PCL 6

| Параметр | Значение |
|---|---|
| Источник бумаги | Автовыбор |
| Двусторонняя | Нет (simplex) |
| Масштаб | По размеру (fit) |
| Центрирование | Да (center) |
| Автоповорот | Да (по умолчанию SumatraPDF) |

### Canon TM-350

| Параметр | Значение |
|---|---|
| Масштаб | По размеру страницы (fit) |
| Ориентация | Авто (по чертежу) |
| Источник | Рулон бумаги |
| Ширина рулона | 24 дюйма (609.6 мм) |

## 📦 Сборка в EXE

### Быстрая сборка (через spec-файл):

```bash
pip install pyinstaller

pyinstaller print_manager.spec
```

### Ручная сборка:

```bash
pyinstaller --onefile --windowed --name "PDF Print Manager" print_manager.py
```

Готовый `PDF Print Manager.exe` будет в папке `dist/`.

> **Важно:** Не забудьте положить `SumatraPDF.exe` в папку `tools/` рядом с EXE,
> или указать путь при первом запуске.

## 🛠️ Техническая архитектура

- **Анализ PDF:** PyMuPDF (`fitz`) — быстрый парсинг размеров страниц
- **Печать:** SumatraPDF CLI — тихая печать с параметрами
- **Мониторинг:** `win32print` (pywin32) — опрос статуса принтеров каждые 3 сек
- **История:** SQLite — таблицы `print_jobs` и `printed_pages`
- **GUI:** tkinter — 4 вкладки: Анализ, Печать, История, Настройки
- **Конфигурация:** JSON файл — настройки принтеров и путей

## ❓ Решение проблем

| Проблема | Решение |
|---|---|
| «SumatraPDF не найден» | Скачайте и положите в `tools/` или укажите путь в настройках |
| «win32print недоступен» | `pip install pywin32` (мониторинг отключён без него) |
| Неправильный размер на плоттере | Проверьте настройки драйвера Canon: рулон 24", без полей |
| Принтер не найден | Проверьте имя в настройках (должно совпадать с Windows) |
| Замятие/ошибка при печати | Устраните проблему на принтере, перезапустите печать |
