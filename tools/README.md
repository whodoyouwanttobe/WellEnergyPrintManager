# SumatraPDF Portable

Для работы модуля печати необходим **SumatraPDF** (портативная версия).

## Установка

1. Скачайте **SumatraPDF Portable** с официального сайта:
   https://www.sumatrapdfreader.org/download-free-pdf-viewer

2. Выберите версию **Portable** (`.zip` архив, ~7 МБ).

3. Разархивируйте `SumatraPDF.exe` в эту папку (`tools/`).

4. Структура должна быть:
   ```
   tools/
   └── SumatraPDF.exe
   ```

> **Права администратора НЕ НУЖНЫ** — SumatraPDF портативная версия
> работает без установки.

## Альтернатива

Если SumatraPDF находится в другом месте, укажите путь
во вкладке **«Настройки»** приложения Print Manager.
